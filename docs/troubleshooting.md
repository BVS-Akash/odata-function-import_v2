# Troubleshooting

**Import absent from `$metadata`:** regenerate/activate SEGW artifacts, verify entity set/cardinality, clear cache. **DPC not reached:** check service alias/name and exact operation name. **Parameters initial:** compare literals to metadata and debug `IT_PARAMETER`. **No rate:** verify TCURR, factors/rate type/date. **Item mismatch:** replace BSIK adapter with FI-approved logic. **500:** inspect `/IWFND/ERROR_LOG` and `/IWBEP/ERROR_LOG`.
